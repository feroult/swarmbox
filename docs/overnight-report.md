## 5. Deviations from the design

Every deviation was made in the same commit as a design fix (the design is the authority and was corrected, not left contradicting the code). The decision log entries carry the reasoning; the headline ones are:

1. **Spike corrections (Phase 0):** command wrapper traps HUP and TERM; no-terminal commands do not use `bash -ic`; the ttyd supervisor stays alive after giving up; the socket fallback starts above 100 characters (`[0.1]`, `[0.2]`).
2. **B1 (Claude Code install):** `UPDATE=self` uses the vendor's native installer, not npm (`[0.3]`); the vendor installer does create `~/.claude` and `~/.claude.json`, so design 6.7 no longer says "never" (`[4a.6]`).
3. **New manifest keys** `YOLO_FLAGS` with `YOLO_ALIAS=0` so OpenCode gets the `--auto` flag without an alias (`[0.3]`). `yolo` falls back to the first agent manifest and ignores `SWARMBOX_YOLO=0` (`[2.4]`).
4. **`-t` is passed only when stdin and stdout are both terminals** (design 3.3 said stdout only; `[3.5]`).
5. **Exit codes the design did not list:** 70 for subcommands not built yet (a temporary state, `[3.1]`), 69 for an ARCH refusal (`[4b.5]`), exit 1 of `swarmbox-mcp` for "written but incomplete" (`[4b.1]`).
6. **`uuid()` removed** from the shell fragment (`[6.1]`); five v0.1.0 behaviours were dropped on purpose when the old tests were retired (`[6.2]`).
7. **serve step 7** leaves an empty `mcp-servers.json` when there is none (`[4a.5]`); `up` makes the nested volume mount point itself, found by the real smoke test (`[3.3]`).
8. **The 3.6 sketch of the stale lock** could delete a live lock; the helper renames the stale lock and re-reads it before deleting (`[3.3]`).
9. **Remote:** connector step last in `up`, warns only, one connector per host, image from the environment only (`[5.4]`); the tunnel token is stored only when the user says yes (`[5.3]`).
10. **`remove` of an image-level tool is allowed;** only `--purge` of an image manifest is refused (`[4b.5]`).
11. **The retired `Dockerfile.v0.1.0` was deleted** together with `build.sh` (`[6.3]`), where the plan only named the scripts.
12. **Test-only switches** (`SWARMBOX_TEST_*`) exist in the product code (host helper, serve, fragment) and are kept out of the configuration table (`[2.2]`, `[3.2]`). They are the price of testing without a third nesting level. Review them.

The full list of every entry whose "Impact on the design" is not "none" is in Appendix A (the third column).
